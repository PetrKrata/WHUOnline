# WHU Online v4.2 — okno přehledu balíčku

Aktualizace verze v4.1. Nahraďte pouze index.html, decks.js a style.css. Ostatní soubory, service worker, katalog a obrázky ponechte. Obnovte Ctrl+F5; v záhlaví je v4.2.

Po dokončení importu klikněte u příslušného hráče na Prohlédnout načtené karty. Otevře se samostatné dialogové okno se sloupci Objective, Ploys a Upgrades zleva. Každý sloupec ukazuje počet karet a jejich obrazové náhledy. Kliknutí na kartu otevře zvětšený detail. Zavřením detailu se vrátíte do přehledu; jeho zavřením do výběru part a balíčků.

Přehled vždy odpovídá hráči, u něhož jste tlačítko použili. Změna odkazu zneplatní původní import a tlačítko zpřístupní až dokončení nového importu. Prázdné skupiny ukazují Žádné karty. Na úzkém displeji se zachovají tři sloupce. Duplicitní kódy se zobrazí podle jejich výskytů.

Syntaxe a rozdělení testovacího balíčku do tří skupin prošly automatickou kontrolou. Vizuální rozložení a návrat mezi dialogy je třeba vyzkoušet v prohlížeči. Další kroky hry se nemění.
