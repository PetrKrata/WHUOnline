# WHU Online — samostatná ONLINE větev

Tato větev obsahuje pouze novou online verzi postavenou nad Firebase / Firestore.

OFFLINE verze zůstává v `main` a ve větvi `offline-v1.0.2` a při vývoji této větve se nemění.

Tuto větev nebudeme běžně slučovat do `main`, protože je záměrně oddělená a neobsahuje offline soubory.
